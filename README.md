# Creatency

**Bring It. Build It. Own It.**

Creatency is a creation platform built around *Ownership Through Progress*. It helps people turn ideas into owned outcomes through guided creation, milestone-based progress and transparent ownership. Creatency is the Guardian of Creation: no meaningful progress is ever lost.

## North Star

> Does this help a creation move from idea to ownership?

If yes, it belongs. If no, it goes in the parking lot.

## Project Zero

Creation #1 is Project Zero: moving Village UpKeep from Bubble to code its owner fully controls. The founder is both the Bringer and the Creator.
